# 设计系统 · 车维通（汽车维修工单与配件领用管理系统）

> 依据需求文档「UI 视觉与交互设计」落地。方向为「公共服务蓝」的专业业务系统风格：重数据可读性、
> 操作效率与状态辨识，不使用装饰性光效、悬浮球、过度渐变或大面积插画。
> 全部变量定义于 `design/mock.css` 的 `:root`，实现阶段直接复用同一套 token。

## 1. 色彩

| 用途 | 变量 | 色值 | 使用说明 |
|---|---|---|---|
| 主色 | `--pri` | `#15344A` | 侧边栏底色、主按钮、关键数字、当前节点 |
| 辅助色 | `--sec` | `#237A8B` | 次级按钮、筛选选中态、普通图表系列 |
| 强调色 | `--acc` | `#2D5B6B` | 链接、信息提示、图表对比系列 |
| 页面背景 | `--bg` | `#F3F7F8` | 主内容区背景，表格与表单用白色容器 |
| 成功 | `--ok` | `#2D7A58` | 已完成、已通过、合格、质保中 |
| 警示 | `--warn` | `#B07A20` | 待确认、低于下限、即将到期 |
| 危险 | `--dan` | `#B03035` | 驳回、不合格、超时、删除确认（仅小面积） |
| 描边 | `--line` | `#DDE6E8` | 卡片/表格/输入框边框 |
| 正文 | `--txt` | `#1E2B33` | 正文与表格内容 |
| 次要文字 | `--mut` | `#6B7C86` | 标签、说明、表头 |

图表系列固定派生顺序：`#15344A → #237A8B → #4FA3B3 → #B07A20 → #B03035 → #5F7078`，
同一含义在不同页面必须使用同一颜色（例：返工恒为 `#B03035`）。

**状态绝不只靠颜色表达**：所有状态标签均带中文文案 + 前置圆点，色弱用户也可辨识。

## 2. 字体与排版

- 字族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 阶梯：页面标题 18px/600、卡片标题 13.5px/600、正文与表格 12.5–13px/400、说明 11.5–12px/400、
  关键指标 23px/600、详情编号 16px/600
- 行高 1.5；正文段落 1.85–1.95（说明性文字）
- **数字一律 `font-variant-numeric: tabular-nums`**（`.num` 类），保证金额、里程、工时列右对齐不跳动
- 字间距：标题 0.3–0.5px，正文 0

## 3. 布局与栅格

- 桌面端：侧栏 220px + 顶栏 56px + 自适应内容区，内容区外边距 24px
- 侧栏分组标题 11px `#6E8894`，菜单项 36px 高、左 3px 激活条、激活底色 `rgba(35,122,139,.30)`
- 卡片圆角 7px（规范要求 6–8px），边框 1px `--line`，**阴影只用于抽屉与弹窗**
- 两栏详情页：主区 `1.6fr` / 侧区 `1fr`，间距 12px
- 看板四列：`repeat(4, 1fr)`，间距 12px，列底色 `#EDF3F4`
- 看板页（维修经营分析）按 1440×900 一屏设计：6 指标 + 6 图表，图表高 150px（小图 132px）

## 4. 间距刻度

`4 / 6 / 8 / 10 / 12 / 14 / 16 / 24`（px）。卡片内边距 16px，卡片头 44px，表格单元 11px 12px，
筛选区 14px 16px，表单项纵向间距 16px、横向 24px。

## 5. 表单规范

- 标签宽 104px（规范 100–120px）右对齐，必填前置红色 `*`
- 单列输入宽 360–520px；搜索下拉框 180–240px（本设计统一 200px）
- 输入框高 32px（登录页 40px），圆角 6px，聚焦时描边转 `--sec`
- 文本域高 72px，可纵向拉伸
- 上传区为虚线框 96px 高，支持多图预览缩略图 76×57，右上角删除按钮
- 关闭抽屉/离开页面前检测未保存内容；复杂表单提供「保存草稿」

## 7. 角色视觉区分

| 角色 | 入口 | 视觉特征 |
|---|---|---|
| 门店经理 / 质检 | 后台管理端 | 深主色侧栏，看板与统计为主，红/橙预警最密集 |
| 服务顾问 | 后台管理端 | 侧栏「接车与预约」「维修工单」常驻，待办优先 |
| 维修技师 | 后台管理端（精简菜单） | 只见本人任务：派工看板、检测登记、我的工时 |
| 仓库人员 | 后台管理端（精简菜单） | 只见配件档案、领退记录、库存批次；报价与确认只读 |
| 车主客户 | 车主门户 | 白色顶栏 64px + 内容流 1180px 居中，无侧栏，渐变 Hero 卡 |

## 8. 交互细节

- 行内操作最多「查看 + 2 个高频操作」，其余收进「更多」
- 审批与流转使用抽屉，抽屉内同时展示单据摘要
- 空状态说明原因与下一步，例如「当前筛选条件下无记录，清空筛选或新建汽车维修工单」
- 加载超过 300ms 显示局部骨架/表格 loading，禁止整页白屏
- 时间统一 `yyyy-MM-dd HH:mm:ss`，由全局格式化函数输出
- 移动端 <768px：侧栏转抽屉、筛选折叠为底部面板、表格转信息卡（编号/状态/时间/负责人）
